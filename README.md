# Dank Image Widget

A customizable image widget for [DankMaterialShell](https://github.com/AvengeMedia/DankMaterialShell).

Display images and animated GIFs directly on your desktop!

## Features

- Display images on your desktop
- Support for animated GIFs
- Custom image file paths
- Resizable desktop widget
- Lightweight QML implementation

## Installation

1. Download or clone this repository.
2. Place the plugin folder inside:

   `~/.config/dms/plugins/`

3. Open DankMaterialShell Settings.
4. Go to **Plugins** and click **Scan**.
5. Enable **Image Widget**.
6. Add the widget through the desktop widgets menu.

## Configuration

Open the Image Widget settings and enter the absolute path to your image.

Example:

`/home/username/Pictures/animation.gif`

## Requirements

- DankMaterialShell 2.0 or newer
- QtQuick
